# Design Philosophy

- Emergence ≠ magic.
- Adaptive routing is a constraint-selection problem.
- Memory systems require both recall and forgetting.
- Forecasting becomes useful when recovery is possible.
- Regime shifts expose policy brittleness.
- Constraint-aware systems should remain interpretable.
